# Community Warcry

Community-maintained balance patches and clarifications for Warcry Matched Play.

We maintain rules through an open contribution process: anyone can report a problem, propose a change, or help playtest. The rules council is the repository's maintainer team. Maintainers review contributions, write precise rules text, and publish versioned balance patches.

**Status: project setup. No stable community balance patch has been released.**
The default branch contains work in progress. Only tagged GitHub releases identify published patches; event organisers choose which release to adopt.

## How changes happen

1. Open an [issue](https://github.com/Community-Warcry/rules/issues/new/choose) describing a balance problem or ambiguity.
2. Maintainers discuss scope and evidence with contributors.
3. Submit a linked pull request containing exact proposed changes.
4. Playtest a specific revision and report the results in the linked issue.
5. Maintainers review the evidence and wording, record their decision, and merge approved changes.
6. Publish a cumulative patch as a tagged release with an effective date.

You do not need Git knowledge to contribute: opening an issue or reporting games is enough. Maintainers can prepare the pull request.

## Project scope

Warcry has three formats: Narrative Play, Open Play and Matched Play. This repository focuses on Matched Play.

Start with points adjustments, targeted ability changes and clarifications. Preserve the core game and faction identities. New factions and major redesigns require a separate scope discussion.

Every proposal must identify its rules baseline and format. Keep bespoke-only and unrestricted results separate, including ally and blessing restrictions, scenario and terrain assumptions.
